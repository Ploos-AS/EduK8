# K8 Classic Clock and Control Timing

## Status

**M4 implementation decision — FROZEN baseline for first Classic schematic**

This resolves the clock/control-timing blocker.

## Baseline CPU clock

K8 Classic v1 uses **1 MHz CPU_CLK** as the normal RUN baseline.

One full CPU hardware cycle is therefore 1000 ns. Manual STEP remains available for arbitrarily slow observation.

The board may later qualify higher clock rates, but 1 MHz is the schematic/BOM qualification point.

## Selected memory timing

Baseline parts:
- control/program EEPROM class: AT28C256, 150 ns maximum read access
- SRAM: AS6C62256-55PCN, 55 ns maximum address access

The control store uses six parallel AT28C256-class slices.

## Control-word latch decision

Classic v1 **does use six 8-bit control-output registers/latches between the control EEPROMs and datapath control nets**.

Reason: the sequencer changes ROM address before datapath state is committed. Registering the 48-bit word prevents EEPROM address-transition glitches from becoming architectural strobes.

This is retained even though 1 MHz leaves generous static access-time margin.

The physical latch/register shall be a 74HC574-class device or equivalent, selected in the BOM after setup/hold timing is checked.

## Four timing phases

A logical microcycle is treated as four conceptual windows:

1. sequencer/address changes
2. EEPROM settles
3. 48-bit control word is captured and datapath settles
4. architectural register/memory update occurs

The schematic may derive these from opposite edges plus explicit phase logic rather than a literal four-phase oscillator. What matters is the ordering and minimum timing.

## Conservative budget

At 1 MHz, 1000 ns is available per cycle.

The design shall reserve at least:
- 200 ns after control-store address change before control capture
- 200 ns after control capture for HC datapath propagation
- 100 ns qualified memory read/write window where applicable
- remaining margin for decode, clock skew and setup/hold

These are design allocations, not substitutes for final component datasheet limits.

AT28C256 150 ns access fits inside the 200 ns control-ROM settle allocation. AS6C62256-55PCN 55 ns access fits inside a 100 ns memory window before register setup margin is applied.

## Memory-cycle rule

MDR capture and SRAM writes occur only in the qualified architectural-update phase.

Address and chip select must already be stable before the active memory edge/window.

EEPROM program writes are never generated by CPU control.

## Control capture

All six control bytes are captured together. Slice skew must not create mixed old/new architectural control words.

The latched outputs, not raw EEPROM outputs, drive state-changing datapath controls.

Raw ROM outputs remain available at debug points.

## Single-step

Manual STEP executes the same complete timing sequence as RUN. It must not bypass control capture or memory timing phases.

Holding the button cannot extend MEM_WRITE indefinitely.

## HALT and reset

HALT stops only at a safe cycle boundary after state-changing strobes are inactive.

Reset asynchronously or synchronously forces safe write/driver inhibition, then restarts the normal phased sequence from the qualified reset state.

## Video interaction

The video timing clock is separate. VRAM arbitration may insert a deterministic CPU VRAM wait, but it cannot shorten the control-ROM or datapath timing windows.

## Higher-speed qualification

1 MHz is guaranteed baseline, not a permanent maximum.

Any higher advertised CPU rate requires:
- worst-case control EEPROM access check
- HC propagation-chain analysis
- SRAM timing check
- setup/hold/skew calculation
- VRAM arbitration check
- hardware or digital timing qualification

No frequency above 1 MHz is claimed until that work passes.

## Pre-freeze timing checks

- verify actual 74HC latch setup/hold values
- verify sequencer-to-ROM address propagation
- verify 200 ns minimum EEPROM settle interval
- verify control capture precedes datapath update
- verify worst-case ALU/AGU chains fit the allocated settle window
- verify 55 ns SRAM read plus decode fits MDR capture
- verify SRAM write pulse width
- verify no raw EEPROM glitch reaches MEM_WRITE or bus-enable controls
- verify STEP and RUN use identical phase ordering
- verify reset/HALT cannot truncate a write pulse

## Result

The blocker is resolved: Classic v1 is schematically qualified around a 1 MHz CPU baseline with registered 48-bit control-ROM outputs and explicit phased timing.
