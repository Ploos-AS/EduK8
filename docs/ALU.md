# K8 Classic ALU v1

The ALU is deliberately built from visible standard logic. It is an educational 8-bit ALU, not a black-box CPU peripheral.

## Arithmetic core

Use two 74HC283-class 4-bit binary adders cascaded as an 8-bit adder. Carry propagates from bit 3 to bit 4 and from bit 7 to the ALU carry output.

    A[7:0] ----> 74HC283 low -> 74HC283 high -> RESULT[7:0]
    B[7:0] ----> 74HC283 low -> 74HC283 high

## ADD

RESULT = A + B + C. The architectural C flag is the bit-7 carry out.

Overflow: V = ~(A7 ^ B7) & (A7 ^ RESULT7). Generate it with ordinary gates so the intermediate signals can be probed.

## SUB

Use two's complement: A - B - borrow = A + (~B) + C.

- B is conditionally inverted.
- The adder carry input is the no-borrow/carry input.
- C=1 means no incoming borrow.
- C=0 means an incoming borrow.
- The resulting C flag is set when no unsigned borrow occurred.

Overflow: V = (A7 ^ B7) & (A7 ^ RESULT7).

## Logic and shifts

Support AND, OR, XOR and NOT using ordinary 74HC gates and a 74HC157-class multiplexer where useful.

Provide separate visible shift logic for logical left/right shifts and rotate-left/right through carry.

## Flags

Expose C, Z, N and V. Z is generated by reduction of all eight result bits; N is RESULT7; V is generated from sign bits and result sign. I and B are not modified by the ALU.

## Control interface

- ALU_OP
- ALU_B_INV
- ALU_CIN
- ALU_OUT_ENABLE
- FLAGS_LATCH

The result reaches the CPU data bus only when explicitly enabled.

## Probe points

Provide labelled points for A[7:0], B[7:0], RESULT[7:0], carry between bits 3/4, final carry, B inverted, CIN, Z, N, V and ALU_OP.

Teaching example: 0x7F + 0x01 produces RESULT=0x80, C=0, N=1, V=1, Z=0.

Teaching subtraction example: 0x00 - 0x01 demonstrates the distinction between unsigned borrow and the architectural C flag.

## FPGA correspondence

Expose equivalent named signals in simulation: alu_a, alu_b, alu_result, alu_carry, alu_overflow, alu_zero, alu_negative, alu_b_inverted and alu_cin.

## Teaching sequence

1. Build a 4-bit adder.
2. Cascade it into 8 bits.
3. Demonstrate unsigned carry.
4. Demonstrate signed overflow.
5. Build subtraction from two's complement.
6. Probe carry propagation with a logic analyser.
7. Compare Classic and FPGA traces.
